**邻接矩阵**是图论中用来表示图的一种数据结构。它用一个二维数组（矩阵）来描述图中各个顶点之间是否有边相连。

---

## 基本定义

对于一个有 **n** 个顶点的图，邻接矩阵是一个 **n × n** 的矩阵 **A**：

- **A[i][j] = 1**：表示顶点 i 和顶点 j 之间有边
- **A[i][j] = 0**：表示顶点 i 和顶点 j 之间没有边

如果是**带权图**，则 A[i][j] 存储的是边的权值（无边时通常用 0 或 ∞ 表示）。

---

## 举例 1：无向图

假设有 4 个顶点：A、B、C、D，边为：A-B、A-C、B-D。

```
    A
   / \
  B   C
  |
  D
```

邻接矩阵（顶点顺序 A, B, C, D）：

|   | A | B | C | D |
|---|---|---|---|---|
| A | 0 | 1 | 1 | 0 |
| B | 1 | 0 | 0 | 1 |
| C | 1 | 0 | 0 | 0 |
| D | 0 | 1 | 0 | 0 |

**特点**：无向图的邻接矩阵是**对称矩阵**，即 A[i][j] = A[j][i]。

---

## 举例 2：有向图

顶点 A、B、C，有向边为：A→B、A→C、C→B。

```
  A → B
  ↓   ↑
  C ──┘
```

邻接矩阵：

|   | A | B | C |
|---|---|---|---|
| A | 0 | 1 | 1 |
| B | 0 | 0 | 0 |
| C | 0 | 1 | 0 |

**特点**：有向图的邻接矩阵**不一定对称**。比如 A→B 存在，但 B→A 不存在。

---

## 举例 3：带权图

顶点 A、B、C，边及权值：A-B(5)、B-C(3)、A-C(8)。

邻接矩阵（无边用 ∞ 表示）：

|   | A | B | C |
|---|---|---|---|
| A | 0 | 5 | 8 |
| B | 5 | 0 | 3 |
| C | 8 | 3 | 0 |

---

## 优缺点

| 优点 | 缺点 |
|------|------|
| 判断两点是否相邻：O(1) | 空间复杂度 O(n²)，稀疏图浪费空间 |
| 实现简单，易于理解 | 遍历某点的所有邻居需 O(n) |
| 适合稠密图 | 添加/删除顶点不方便 |

---

## 一句话总结

邻接矩阵就是用一张“表格”记录图中每两个顶点之间有没有边（或边的权重），行和列都代表顶点。
